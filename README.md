# Ripple-Button
a simple and intractive beginner friendly project using HTML,CSS AND JS.

# How it Works-
when the user hover anywhere over the button, a ripple animation will happen which will automatically change the button's color

# Project Purpose -
this was created by me in my 1st year to practice concepts of Java Script and also Frontend Development like DOM manipulation, event handling and CSS features like animations.
